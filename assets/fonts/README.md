# Fuentes de la interfaz

La aplicación empaqueta estas familias para mantener la misma tipografía en Windows sin conexión:

- IBM Plex Sans, variable: texto general.
- IBM Plex Sans Condensed: títulos y rótulos.
- IBM Plex Mono: cifras y telemetría.

Origen: [Google Fonts, IBM Plex Sans](https://github.com/google/fonts/tree/main/ofl/ibmplexsans), [IBM Plex Sans Condensed](https://github.com/google/fonts/tree/main/ofl/ibmplexsanscondensed) y [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).

Cada familia incluye su archivo OFL correspondiente. Las fuentes quedan sujetas a los términos de esas licencias.
